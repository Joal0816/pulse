# Design System: Pulse Telemetry (Anti-AI-Slop Craft)

## Mode: OPERATE
Precision telemetry interface. Every pixel must feel engineered, deliberate, and dense with genuine utility. Zero cartoonish glassmorphism, zero generic gradient purple cards, zero fake AI marketing fluff.

## Visual Direction: "Mission Radar"
- **Base**: Ultra-deep matte obsidian (`#0b0f14`), charcoal card surfaces (`#111720`), subtle hairline borders (`#1b2432`).
- **Typography**:
  - Display & Numbers: `JetBrains Mono` or high-density tabular monospace font (`font-mono`, `tabular-nums`) for all metrics, latencies, dates, status codes.
  - Interface text: Clean modern sans (`Inter` / system sans) with tight tracking and high contrast.
- **Accents & Semantics**:
  - Live / Healthy: Crisp Emerald (`#10b981`), pulsing indicator dot for active heartbeats.
  - Degraded / Warning: Amber (`#f59e0b`).
  - Outage / Error: Crimson (`#ef4444`).
  - Analytics Accent: Signal Cyan / Electric Cobalt (`#06b6d4` / `#3b82f6`) for timeseries volume curves.
  - Surface Neutral: `#64748b` for labels, muted microcopy.

## Anti-AI-Slop Rules
1. No centered generic marketing cards with vague illustrations.
2. Every card displays authentic real data or actionable empty state with precise instructions.
3. Micro-interactions: Crisp hover states, 150ms transitions, keyboard-friendly navigation.
4. Mobile-first responsive layout that scales seamlessly from a 360px Android phone screen to an ultrawide desktop monitor.
5. PWA Manifest & App Shell icons included with crisp vector/canvas representations.
